# surge-modules

Surge modules, converted and maintained here.

## Spotify

Removes Spotify ads and unlocks some premium features. Audio quality cannot be set to Very High. Log in again after enabling the module to apply the full configuration.

Converted from the Loon plugin by devchristian1337 (2026-11-10):
https://raw.githubusercontent.com/devchristian1337/loon-plugins/refs/heads/main/Plugins/Spotify.lpx

Install in Surge:

```
https://raw.githubusercontent.com/jobslead/surge-modules/main/Spotify/Spotify.sgmodule
```

Or open this link on iOS:

```
surge:///install-module?url=https%3A%2F%2Fraw.githubusercontent.com%2Fjobslead%2Fsurge-modules%2Fmain%2FSpotify%2FSpotify.sgmodule
```

Before enabling it, disable any other Spotify module (e.g. the old SIJULY / app2smile one), otherwise the two modules will fight over the same URLs.

Notes on the conversion are in the header comments of `Spotify/Spotify.sgmodule`.
